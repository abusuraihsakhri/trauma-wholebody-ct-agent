Rule definitions and limitations

The demonstrator reproduces the three synthetic triggers in agents/workers.py: primary metric > 25; secondary metric > 12 or critical flag; and descriptor containing DISCORDANT, ANOMALY, MUTANT, VIOLATION, FAIL, or REJECT (case-insensitive). These numerical limits are arbitrary demonstration settings, not diagnostic cutoffs or AAST Organ Injury Scale criteria.

Results remain in this browser session. The tool has no external data requests, persistent storage, image upload, CT processing, or live patient monitoring. The separately hosted Python API is not called.
